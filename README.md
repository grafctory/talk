# @grafctory/talk

Conversational AI access to knowledge graphs.

**@grafctory/talk** is the conversational AI module of the [Grafctory][grafctory] model-driven knowledge graph
framework. It connects AI agents to the graph through MCP servers, so they can explore and analyse your data in plain
conversation.

> [!NOTE]
>
> Coming soon: watch this repository to be notified of the first release.

[grafctory]: https://github.com/grafctory

# Installation

```shell
npm install @grafctory/talk
```

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.

| Package           | Description                           |
|-------------------|---------------------------------------|
| [@grafctory/talk] | MCP servers for knowledge graph access |

[@grafctory/talk]: https://grafctory.github.io/talk/modules/_grafctory_talk.html
