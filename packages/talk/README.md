Connects AI agents to knowledge graphs, so they can explore and analyse the graph in plain conversation.

[@grafctory/talk]: https://github.com/grafctory/talk

# Installation

```shell
npm install @grafctory/talk
```

> [!IMPORTANT]
>
> Node.js 22 or later is required.

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.
